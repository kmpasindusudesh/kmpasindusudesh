# Pasindu's AI profile theme

## Upload to GitHub

1. Extract `Pasindu_AI_Profile.zip`.
2. Open your profile repository: `kmpasindusudesh/kmpasindusudesh`. If it does not exist yet, create a public repository named `kmpasindusudesh` under your account.
3. Upload **README.md and the complete assets folder** to the repository root. Replace the old README when prompted. Keep the folder named `assets`.
4. Commit the changes and open your GitHub profile.

You can drag the README file and the assets folder together into GitHub's **Add file → Upload files** screen. Do not upload the ZIP itself. The README and assets must be alongside each other in the root, with no extra enclosing folder.

You do not need to upload this setup guide or the preview HTML.

## What's included

- A seamless 3D neural-network header animation, rendered to a GIF.
- A static SVG header for a motion-free option.
- Local technology badges, three project illustrations, contact buttons and a footer.
- An updated README using your original education, links, technologies and projects.
- A self-contained HTML preview with dark and light themes.

All main visuals are local assets. They work without API keys or GitHub Actions. Only the optional activity cards use external services.

## Quick customizations

- **Turn off motion:** In README.md, change `./assets/hero.gif` to `./assets/hero-static.svg`.
- **Edit your description or projects:** Update the normal Markdown text in README.md. Project artwork uses editable SVG text.
- **Add direct project links:** Link each project heading to its real repository URL when available. No project repository URLs have been guessed.
- **Change colours:** The SVG files use navy `#080e1c`, cyan `#65e4f2` and purple `#b39aff`. Edit SVG files in a text editor. The GIF is a rendered animation, so SVG edits do not change it.
- **Contact details:** Your existing GitHub and LinkedIn links are already included.

## Preview and compatibility

Open `Pasindu_AI_Profile_Preview.html` in a browser to see the theme locally. The preview is an approximation of GitHub's Markdown layout; GitHub may use slightly different spacing and fonts. The animation is a GIF, not an interactive 3D model. GitHub's surrounding page follows each visitor's theme.

The collapsed activity section retains GitHub Readme Stats and uses the current documented Streak Stats endpoint. Those services may be unavailable or rate-limited; the rest of the profile does not depend on them.
